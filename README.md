## 整理与移出的惯例

日志是**捕获与思考的现场记录**，不是规格的家。整理日志时：

1. **主题分节**：口述流水按主题组织为 `##` 小节，只做结构化与压缩，不改变判断性表述
2. **规格移出**：整理中产生的规格、规划、定义类内容，移到对应的家（规格→ docs/specification 或 handbook、路线规划→ data/roadmap、洞察→ data/insight），移出后**原文删除**，留一行指引链接指向新位置
3. **摘要替代**：被移出的段落以一行摘要+链接保留在原节，保证日志的时间线可读——读者知道这里曾想过什么、现在住哪

依据：单一事实源——规格只活在一处（roadmap/handbook/specification），journal 不留副本；journal 的价值是过程与时间线，不是规格的存储层。

4. **兜底流向 profile/default.md**：整理中被移出的内容，**默认全部先移到 `data/profile/<作者>/default.md` 作为材料备用**——不论看起来是否"像规格/规划"。认领升级是后置动作：未来某次整理中认为某段材料成熟了，才从 default.md 升级进对应的家（规格/路线图/洞察），并从 default.md 删除。**整理时不做归宿判断**——那是一次新的判断工作，违背"判断降级为整理"；default.md 允许混乱，它就是材料的暂存区。
